# Evaluation

## Primary Metric

Lobby fulfilment rate: the percentage of posted goals that reach their required headcount within a reasonable window.

## Secondary Metrics

- Time-to-first-request.
- No-show rate.
- Resource-request response rate.
- User-reported clarity and safety for anonymous and gender-filter features.

## Pilot

The first pilot will use 15-20 students from the same batch or hostel block. Some goals may be seeded so that the request and lobby workflows can be tested under active conditions.
