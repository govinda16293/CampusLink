# Proposed Solution

CampusLink provides a structured goal-posting platform restricted to verified college students.

## Features

- College email verification.
- Public feed for posted goals.
- Category and date filters.
- Request-to-join and approval workflow.
- Lobby chat after a group forms.
- Private chat for notes/resource requests.
- Anonymous posting before acceptance.
- Gender-preference filter for sensitive goals.
- Reliability score based on completed goals and no-show history.
- Report and block controls.

## Out of Scope

Duplicate or near-duplicate detection is not part of the first implementation. Matching intelligence will stay rule-based rather than machine-learning based.
