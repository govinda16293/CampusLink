# Project Report - Final

The final project report for CampusLink, written in the UCS503 course report template.

## Files

- `report.pdf` - the compiled final report (22 pages).
- `main.tex` - the LaTeX source of the report.
- `tietreport.cls` - the course template's document class.
- `figures/` - diagrams and screenshots used in the report: system architecture, use case, class, Level 0 and Level 1 DFDs, sequence, activity, goal and join-request state diagrams, and app screenshots.

## Contents

1. Introduction - background, problem statement and objectives.
2. Methodology and Design - system architecture, high-level design (UML diagrams and DFDs), technical stack, and implementation details.
3. Results and Evaluation - testing methodology, performance metrics and analysis.
4. Conclusion - summary, key findings, future work and final remarks.
5. Bibliography.

## Compiling on Overleaf

1. Upload `main.tex`, `tietreport.cls` and the whole `figures/` folder.
2. Set the compiler to pdfLaTeX (Menu -> Compiler).
3. Press Recompile twice so the contents and references settle.
